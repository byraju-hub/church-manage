# 부평동부교회 교적 관리 — 프로토타입

SvelteKit + Cloudflare Pages로 만든 **교적 관리 프로그램 프로토타입**입니다.
실제 DB(Supabase)에는 연결하지 않고, 가상 데이터(재적 723명, 주일 출석 약 430명 규모)로 동작합니다.
교적 프로그램에 필요한 **구조·기능·화면·입력 항목**을 점검하고, 실제 개발자가 이를 기준으로 만들 수 있게 하는 것이 목적입니다.

> 모든 이름·전화·주소는 만들어 낸 값입니다. 실제 교인 자료(엑셀 등)는 저장소에 올리지 않습니다 (`.gitignore`로 차단).

## 무엇을 볼 수 있나
| 메뉴 | 주소 | 내용 |
|---|---|---|
| 대시보드 | `/` | 통합 검색창, 숫자 카드 8개(재적·주일/소그룹/교육부서 출석·새가족·심방·장기 결석·생일), 캘린더, 출석 추이 |
| 교적 | `/members` `/new` `/<id>` `/newcomers` `/households` `/candidates` | 교인 목록(목록·상세 2단, 기본·복수·항목별 검색), 교인 등록, 교적 카드, 새가족 정착, 세대, 확인 목록 |
| 공동체 | `/communities` `/attendance` | 편성표(공동체 3개·소그룹 27개+로뎀나무숲, 인도자·장소), 주일 출석 등록 |
| 심방 | `/visits` | 등록, 목록 검색, 달력 검색, 녹음·문서 분석으로 내용 채우기 |
| 조직 | `/orgs` | 당회·시무집사회·시무권사회·남전도회(1~6)·여전도회(1~10)·교회 조직표(위원회 9개) |
| 통계 | `/stats` `/reports` `/documents` | 주일·소그룹 출석, 임직, 세례 통계 / 명단 / 문서 출력(교적부·증명서·요람·생일 명단, 인쇄·PDF) |
| 관리자 | `/admin` `/settings` | 회원·권한(카카오 가입 승인, 3단계 등급, 등급 설정, 접속기록), 교인구분·소그룹·조직표 설정 |

**카카오로 회원가입·로그인 → 최고관리자가 회원 목록에서 승인하고 등급(1~3) 지정 → 사용** 방식입니다. 프로토타입에서는 '카카오로 로그인'을 누르고 가상의 카카오 계정을 고릅니다. (최고관리자: 정담임)
상단 회원 이름을 누르면 **다른 회원으로 보기**(등급마다 화면이 어떻게 다른지)와 **'교적 데이터 초기화'**가 있습니다. 입력한 내용은 각자 브라우저에만 저장됩니다.

## 핵심 설계
- **교인구분은 3단계 카테고리**: 교인 / 미등록·타교인 → 장년·새가족·청년부·중고등부·유초등부·유치부·영아부 → 예배출석·가끔출석·불출석·장기결석자. 별세·이사/이민·보관은 1단계. 이름은 관리자가 바꿈.
- **재적 상태·신급·직분은 이력에서 계산** (등록·전입·복적·보류·보관·전출·별세·제적 등). 지금 값을 직접 고치지 않고 이력을 쌓음.
- **직분과 신분**: 직분(목사·전도사·사모·장로·시무집사·권사·서리집사)마다 고를 수 있는 신분이 다르며, 교역자 직책(담임·부·교육 목사, 전임·교육 전도사)은 직분 선택에 포함. 임직일·임직교회는 장로·시무집사·권사에게 적음.
- **세대 하나 + 대가족**: 한 사람은 한 세대에만 속하고, 같은 집이 아닌 가족은 대가족 세대주/관계로 따로 이음.
- **공동체·소그룹은 출석부 자료**를 가져와 보여 줌 (출석 기록·인도자 특이사항은 출석부에 있음).
- **회원·등급**: 카카오 로그인(홈페이지와 동일). 최고관리자가 회원 목록에서 승인하고 3단계 등급을 지정 — 1등급 열람 / 2등급 교적 담당(수정·출력) / 3등급 교역자(+심방). 등급마다 할 일은 최고관리자가 바꿀 수 있음. **심방(열람·등록·녹음 분석)은 심방 권한이 있는 등급만.**
- 심방은 상태(계획/완료) 없이 등록, 방법은 대면·전화.
- 재적 이력을 남기면 교인구분이 자동으로 맞춰지고, 동명이인은 등록 순서대로 A·B·C가 자동으로 붙음.
- 주민등록번호는 두지 않음. 개인정보 동의 기록, 접속기록(3년), 변경 이력, 5년 뒤 인적사항 삭제(보관 제외) 구조 포함.

자세한 결정 사항과 남은 질문은 **[`docs/decisions.md`](docs/decisions.md)** 를 보세요.

   │  │  ├─ config.ts             교인구분 3단계 · 공동체/소그룹 편성 · 교회 조직표 · 회의 의장/서기
   │  │  ├─ derive.ts             이력에서 재적 상태 · 신급 · 직분 · 호칭 계산
   │  │  ├─ calendar.ts           부활주일 등 교회 절기 계산, 캘린더 색
   │  │  ├─ store.svelte.ts       저장소 (브라우저 localStorage). 실제 개발 시 Supabase 호출로 교체
   │  │  ├─ seed.ts               시험용 인물 · 회원 · 등급 (모두 가상)
   │  │  ├─ generate.ts           가상 교인 생성기 (재적 723명 규모)

   └─ routes/
      ├─ +layout.svelte · app.css            모든 화면 공통 (스타일)
      ├─ api/visit-analyze/                  심방 녹음·문서 분석 서버 기능
      └─ (app)/                              교적 화면 (폴더 이름의 (app) 은 주소에 나타나지 않음)
         ├─ +layout.svelte                   카카오 로그인 · 상단 메뉴 · 휴대폰 아래 메뉴
         ├─ +page.svelte                     대시보드

## 심방 녹음·문서 분석 (선택 기능)
심방 등록 화면의 '녹음·문서로 채우기'가 `/api/visit-analyze`를 부릅니다.
- 화면에서 **바로 녹음**하거나 파일을 올림. 녹음 → `OPENAI_API_KEY`로 받아쓰기 → `ANTHROPIC_API_KEY`(Claude API)로 요약해 구분·내용·말씀·찬송·후속 조치·동행자를 채움
- PDF·텍스트 → 바로 요약
- **키가 없으면 시연용 예시**를 보여 줍니다. 로컬은 `.env`, 배포는 Cloudflare Pages 환경 변수에 넣고, `.env.example`을 참고하세요. 키는 저장소에 올리지 않습니다.
- 심방 내용은 민감한 정보라 외부 서비스로 전송됩니다. 실제 도입 전에 동의·보관 방침을 정해야 합니다.

## 배포 (Cloudflare Pages)
Cloudflare Pages에 이 저장소를 직접 연결해 두었습니다. `main` 브랜치가 바뀔 때마다 자동으로 빌드·배포됩니다.

- Production branch: `main`
- Build command: `npm run build`
- Build output directory: `.svelte-kit/cloudflare`
- Environment variable: `NODE_VERSION` = `22`
