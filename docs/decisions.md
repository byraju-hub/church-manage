## 정한 것
### 회원·권한
- **카카오로 회원가입·로그인** (홈페이지와 같은 방식) → **최고관리자 승인** → 사용. 승인 전에는 아무것도 볼 수 없다.
- 최고관리자가 '관리자 › 회원 · 권한 › 회원 목록'에서 회원마다 **3단계 등급**을 정한다.
  - A · 전임 교역자(수정·내려받기·출력·심방) / B · 교적 관리(수정·내려받기·출력) / C · 열람. 등급 이름과 권한은 '등급 설정'에서 바꿀 수 있다.
  - 최고관리자는 모든 권한 + 가입 승인·등급 지정. 설정 메뉴(사이트 관리자)는 기본으로 최고관리자만.
- **심방은 A 등급만** (등급 설정·최고관리자 여부로 바꿀 수 없음): 심방 메뉴(심방 목록·캘린더 보기·소그룹 특이사항·심방 등록), 교적 카드의 심방 탭·디모데 메모·인도자 특이사항, 대시보드 최근 심방·한 달 심방 수. B·C 등급에는 메뉴와 칸 자체가 보이지 않는다. 단 달력의 '심방 계획'(이름·날짜)은 모든 회원에게 보인다.
- 접속기록: 로그인·검색·열람(목록의 상세 보기 포함)·수정·내려받기·출력·심방·권한 변경.
- [실제 시스템] 권한은 화면이 아니라 DB 접근 규칙(RLS)과 서버에서 막는다. (`0001_registry.sql` 맨 아래 예시)

### 교인 정보
- **교인구분은 3단계 카테고리**: 교인 > 장년·새가족·청년부·중고등부·유초등부·유치부·영아부 > 예배출석·가끔출석·불출석(장년만)·장기결석자. 미등록/타교인·별세·이사/이민·보관은 1단계. 이름은 관리자가 바꿈. (교육부서는 따로 칸을 두지 않고 2단계로 합침)
- **재적 상태는 이력에서 계산**(등록·전입·복적·보류·보관·전출·별세·제적). '보관'은 삭제할 수 없는 교적이라 5년 자동 삭제에서 제외.
- **직분과 구분**: 직분(목사·전도사·사모·장로·시무집사·권사·서리집사)마다 고를 수 있는 구분이 다름. 시무집사는 '안수집사'가 아님. 임직일·임직교회는 장로·시무집사·권사에게만 적고, 타교 임직은 임직교회 칸으로 표시.
- **교역자 직책**(담임목사·부목사·교육목사·전임전도사·교육전도사)은 직분 선택에 함께 있음. 심방 기록은 교육전도사를 뺀 전임 교역자까지만 열람.
- **세대 하나 + 대가족**: 한 사람은 한 세대에만 속하고, 같은 집이 아닌 가족은 '대가족 세대주/관계'로 따로 잇는다. 등록 화면의 '신앙세대주/관계'는 [이름][검색][의][관계][세대주정보가져오기] 한 줄.
- **재적 이력이 기준**: 별세·전출·제적·보관·보류·등록을 기록하면 교인구분 1단계(별세·이사/이민·보관·교인)가 자동으로 맞춰진다.
- **입력 규칙**: 동명이인 구분은 같은 이름이 있으면 등록 순서대로 A, B, C… 자동, 문자 수신 거부는 휴대폰 옆 체크, 주소는 도로명 검색으로 고르면 우편번호도 자동 입력(우편번호 칸 없음), 직업·직장은 한 칸, 인도자는 교인만, 사진은 올릴 때 자르고 용량을 줄임.
- 주민등록번호는 교적에 두지 않는다. 일괄 동의는 새 시스템 시작 시 한 번에 받고 동의 기록으로 남긴다.

### 조직·출석
- **출석은 두 가지, 따로 저장**: 소그룹에 속한 교인은 한 주일에 출석 기록이 2개 생긴다.
  1) **주일 오전예배 출석**: 교적 '출석' 화면에서 등록. 명단(공동체·소그룹 순) 체크와 별도로 **전체 출석 인원**을 입력하고, 그 외 인원 = 전체 − 명단 체크. 대시보드 '주일 출석'·장기 결석 알림·통계 주일 출석에 쓴다.
  2) **주일 오후 소그룹 모임 출석**: 홈페이지 출석부에서 소그룹 인도자가 등록. 대시보드 '소그룹 출석'·공동체 편성표·소그룹 화면·통계 소그룹 출석·명단 출석률에 쓴다.
  (DB: `worship_attendance` · `worship_totals` · `group_attendance` 표)
- **교인구분 3단계는 4가지**: 예배출석 · 가끔출석 · 불출석 · 장기결석자.
- **장기 결석자 알림**: 교인구분이 '교인 › … › 예배출석·가끔출석'인 사람 중 **2달 이상 주일에 나오지 않은 사람**만 대시보드 알림에 올린다. (재적 상태가 아니라 교인구분 기준, 불출석·장기결석자로 이미 분류된 사람은 제외). 알림에서 '장기결석자로' 버튼으로 바로 분류.
- **공동체·소그룹은 출석부 자료**: 공동체 3개(뿌리·줄기·열매, 출생 연도로 구분), 소그룹 27개, 열매 공동체에 자녀 돌봄 편성 '로뎀나무숲'. 장년만 소그룹에 속하고, 청년·교육부서는 교인구분 2단계로 구분.
- **교회 조직표**: 2026년도 조직표 순서대로 예배·선교·공동체·교육·재정·관리·봉사·기획·미디어 위원회(9개)와 부서 36개. 위원회마다 위원장(장로), 부서마다 부서장과 담당자(여러 명). 공동의회·당회·제직회의 의장·서기도 둠. 교인의 '교회봉사'는 부서를 최대 3개까지 고름. 조직표는 문서 출력(PDF)도 됨.
- **새가족 교육**은 수료 여부를 기록(과정은 늘릴 수 있게 구조만 열어 둠).

### 심방
- 상태(계획/완료) 없이 등록하고, 앞으로의 날짜면 달력에 심방 계획으로 보임. 방법은 대면·전화.
- 동행자는 이름을 쉼표로 이어 쓰며, 교적에 있는 이름이 쓰임(동명이인이면 목록에서 선택, 교적에 없으면 그대로 기록).
- 녹음·PDF·텍스트를 올리면 AI가 구분·내용·말씀·찬송·후속 조치·동행자를 채워 줌(선택 기능, API 키 필요, 없으면 시연용). 올린 파일은 저장하지 않지만 외부 서비스로 전송되므로 동의·보관 방침이 필요.

### 문자 발송
- 교인 목록의 '문자 보내기'(A 등급만): 검색 결과 전체에게 SMS·LMS. 문자 수신 거부·휴대폰 없음·같은 번호는 자동 제외, {이름} 치환, 예상 비용 표시, 접속기록에 남김.
- 발송은 솔라피(SOLAPI) API. 환경 변수 SOLAPI_API_KEY · SOLAPI_API_SECRET · SOLAPI_SENDER(솔라피에 등록한 발신번호), 시험용 SOLAPI_TEST_TO. 키가 없으면 시연만.
- [실제 시스템] 서버에서 로그인·A 등급을 확인하고, 번호는 교인 ID로 DB에서 다시 찾고, 발송 기록 표를 둔다. 광고성 문자 규정 확인.

### 검색
- 대시보드 통합 검색: 교인·소그룹·세대·심방·메모·조직을 한꺼번에.
- 교인 검색: 기본(이름·전화) / 복수(이름을 쉼표로, 교적의 이름으로 확정) / 항목별(검색할 칸을 골라서).

## 연동이 필요한 곳 (개발자 확인)
1. 출석부(공동체 편성, 출석 기록, 인도자 특이사항): 읽기만 할지, 교적에서 출석도 입력할지.
2. 교육부서 보고서(영아부~청년부 출석 통계).
3. 스데반정보 덤프: 심방, 헌금(헌금번호 ↔ 교적 ID 대응).
4. 음력 생일 → 해당 연도 양력 변환(프로토타입은 같은 월·일로 표시).
5. 심방 녹음·문서 분석: 받아쓰기·요약 서비스 선정, 개인정보 처리 방침.

## 아직 정하지 못한 것
- 새가족 교육 수료 시 교인구분을 자동으로 바꿀지.
- 새가족 교육의 주차별 출석·참여도를 기록할지.
- 휴직·무임·타교 구분: 지금은 비고(휴직·무임)와 임직교회(타교)로 처리.
- 심방 계획의 자동 배정 규칙(교역자·공동체).
- 교인구분(예: 교인 > 장년 > 불출석)과 재적 이력(예: 보류)이 어긋날 때 무엇을 기준으로 할지.
- 소그룹 인도자 특이사항을 교적에서도 입력하게 할지(지금은 출석부 자료로 보여 주기만, 심방 권한자만 열람).
- 증명서에 넣을 교회 직인 이미지와 발급 대장 운영 방식.
