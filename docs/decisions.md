## 정한 것
- **교인구분은 3단계 카테고리**: 교인/미등록·타교인 > 장년/청년/교육부서/새가족 > 예배출석/가끔출석/불출석. 별세·이사/이민·보관은 1단계. 이름은 관리자가 바꿈.
- **재적 상태는 이력에서 계산**(등록·전입·복적·보류·보관·전출·별세·제적). '보관'은 삭제할 수 없는 교적이라 5년 자동 삭제에서 제외.
- **직분과 신분**: 직분(목사·전도사·사모·장로·시무집사·권사·서리집사)마다 고를 수 있는 신분이 다름. 시무집사는 '안수집사'가 아님. 임직일·임직교회는 장로·시무집사·권사에게만 적음. 타교 임직은 임직교회 칸으로 표시.
- **교역자 직책**(담임목사·부목사·교육목사·전임전도사·교육전도사)은 신분과 별개 칸. 심방 기록은 교육전도사를 뺀 전임 교역자까지만 열람.
- **세대 하나 + 대가족**: 한 사람은 한 세대에만 속하고, 같은 집이 아닌 가족은 '대가족 세대주/관계'로 따로 잇는다.
- **공동체·소그룹은 출석부 자료**: 공동체 3개(뿌리·줄기·열매, 출생 연도로 구분), 소그룹 27개, 열매 공동체에 자녀 돌봄 편성 '로뎀나무숲'. 장년만 소그룹에 속하고, 청년·교육부서는 '교육부서' 칸.
- **교회 조직표**: 위원회 9개 아래 실무부서. 교인의 '교회봉사'는 부서를 여러 개 고를 수 있음.
- **새가족 교육**은 수료 여부를 기록(과정은 늘릴 수 있게 구조만 열어 둠).
- **일괄 동의**는 새 시스템 시작 시 한 번에 받고, 동의 기록 칸으로 남긴다.
- 주민등록번호는 교적에 두지 않는다.

## 연동이 필요한 곳 (개발자 확인)
1. 출석부(공동체 편성, 출석 기록, 인도자 특이사항): 읽기만 할지, 교적에서 출석도 입력할지.
2. 교육부서 보고서(영아부~청년부 출석 통계).
3. 스데반정보 덤프: 심방, 헌금(헌금번호 ↔ 교적 ID 대응).
4. 음력 생일 → 해당 연도 양력 변환(프로토타입은 같은 월·일로 표시).

## 아직 정하지 못한 것
- 새가족 교육 수료 시 교인구분을 자동으로 바꿀지.
- 새가족 교육의 주차별 출석·참여도를 기록할지.
- 휴직·무임·타교 신분: 지금은 비고(휴직·무임)와 임직교회(타교)로 처리.
- 심방 계획의 자동 배정 규칙(교역자·공동체).
- 교인구분(예: 교인 > 장년 > 불출석)과 재적 이력(보류 등)이 어긋날 때 무엇을 기준으로 할지.
