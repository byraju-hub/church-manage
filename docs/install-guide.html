교회 교적 관리 시험판

설치 가이드 · 2026년 10월 기준

제작: byraju (github.com/byraju-hub)  ·  문의: byraju@naver.com

먼저 알아 두세요 이 프로그램은 화면과 기능을 시험해 보는 시험판입니다. 데이터베이스가 없고, 가상 데이터가 들어 있으며, 입력한 내용은 쓰는 사람의 브라우저에만 저장됩니다. 실제 교인 정보를 넣어 운영하면 안 됩니다. (브라우저 자료가 지워지면 사라지고, 개인정보를 지킬 장치도 없습니다.) 실제로 쓰려면 개발자가 데이터베이스와 로그인·권한을 붙여 정식 시스템으로 만들어야 하고, 그때 필요한 내용은 저장소의 docs/handover.md에 정리되어 있습니다.

1. 준비물

준비물설명
컴퓨터Windows 또는 Mac. 인터넷 연결
Node.js 22.17 이상nodejs.org에서 LTS 버전을 받아 설치합니다. (설치 뒤 터미널의 node -v로 확인)
GitHub 계정 (선택)인터넷에 올릴 때만 필요합니다.
Cloudflare 계정 (선택)인터넷에 올릴 때만 필요합니다. 무료 계정이면 됩니다.

2. 방법 A — 내 컴퓨터에서 실행해 보기

  1. 소스 받기. github.com/byraju-hub/church-manage 페이지에서 초록색 Code 버튼 → Download ZIP을 받아 압축을 풉니다. (Git을 쓴다면 git clone https://github.com/byraju-hub/church-manage.git)
  2. 터미널 열기. 압축을 푼 폴더에서 터미널을 엽니다. Windows는 폴더 빈 곳을 Shift + 오른쪽 클릭 → "터미널에서 열기"(또는 PowerShell).
  3. 필요한 부품 내려받기 (처음 한 번, 몇 분 걸립니다). 
    npm ci
  4. 실행. 
    npm run dev
  5. 브라우저에서 열기. 터미널에 나온 주소(보통 http://localhost:5173)를 엽니다. 소개 화면에서 데모 사이트 구경하기를 누르면 정담임 목사(최고관리자)로 바로 들어갑니다.

끝낼 때는 터미널에서 Ctrl + C를 누릅니다. 입력한 내용을 처음 상태로 되돌리려면 로그인 뒤 위쪽 이름을 눌러 교적 데이터 초기화를 고르세요.

3. 방법 B — 인터넷에 올리기 (Cloudflare Pages, 무료)

이 시험판은 Cloudflare Pages에서 돌아가도록 만들어져 있습니다. 한 번 연결해 두면 GitHub 저장소가 바뀔 때마다 자동으로 다시 올라갑니다.

  1. 저장소 복사. GitHub에서 위 저장소 페이지의 Fork 버튼으로 내 계정에 복사합니다.
  2. Cloudflare 연결. dash.cloudflare.com에 로그인 → Workers & Pages → Create → Pages → Connect to Git에서 GitHub를 연결하고 내 저장소를 고릅니다.
  3. 빌드 설정. 아래처럼 넣습니다.
    항목값
    Production branchmain
    Build commandnpm run build
    Build output directory.svelte-kit/cloudflare
    Environment variableNODE_VERSION = 22
  4. Save and Deploy. 몇 분 뒤 프로젝트이름.pages.dev 주소가 생깁니다.
Cloudflare 화면의 메뉴 이름은 바뀔 수 있습니다. 이름이 다르면 "Pages", "Git 연결", "빌드 설정"에 해당하는 곳을 찾으세요.

4. 우리 교회에 맞게 바꿔 보기

로그인한 뒤 위 메뉴의 관리자를 누르면 아래 항목을 직접 바꿀 수 있습니다. 모두 쓰는 브라우저에만 저장됩니다.

  • 교회 설정 › 기본 설정 — 교회 이름(화면 위쪽 제목과 문서에 쓰임), 주소, 로고, 직인, 증명서 양식, 모임 이름(공동체/교구/지역, 소그룹/구역/목장 등)
  • 교회 설정 › 연간 설정 — 올해 표어, 나이 계산 방식, 연간 계획표 엑셀 등록, 공동체·전도회 출생 연도, 교육부서 기준
  • 교회 설정 › 교회 조직표 · 소그룹 편성 — 위원장·부서장·교역자, 공동체와 소그룹 추가·삭제·이름 바꾸기
  • 프로그램 설정 — 교인구분, 코드표, 백업(전체 내려받기·되살리기)

처음 들어 있는 가상 인물과 교인은 소스(src/lib/registry/seed.ts, generate.ts)에서 만들어집니다.

5. 선택 기능 — 키가 있어야 동작합니다

아래 기능은 외부 서비스의 키를 넣어야 실제로 동작하고, 키가 없으면 예시 화면이 나옵니다. 시험해 보는 데는 키가 필요 없습니다.

기능필요한 키 이름
교인 등록카드 사진 읽기, 심방 내용 분석ANTHROPIC_API_KEY (모델을 바꾸려면 ANTHROPIC_MODEL)
심방 녹음 받아쓰기OPENAI_API_KEY
문자 보내기 (솔라피)SOLAPI_API_KEY, SOLAPI_API_SECRET, SOLAPI_SENDER (시험용 SOLAPI_TEST_TO)
  • 내 컴퓨터: 폴더의 .env.example을 복사해 .env로 이름을 바꾸고 값을 적습니다.
  • Cloudflare: 프로젝트의 Settings → Variables and Secrets에 같은 이름으로 넣습니다.
키는 비밀번호와 같습니다 키를 GitHub 같은 공개된 곳이나 메신저에 올리지 마세요. 심방 내용·등록카드 사진·문자 번호는 외부 서비스로 전송되므로 가상 자료로만 시험하세요.

6. 자주 묻는 질문

증상해결
npm을 찾을 수 없다고 나옵니다Node.js를 설치한 뒤 터미널을 닫았다가 다시 열어 보세요.
npm ci에서 Node 버전 오류가 납니다Node.js를 22.17 이상으로 올려 설치하세요. (node -v로 확인)
주소가 5173이 아닙니다이미 쓰는 번호는 건너뜁니다. 터미널에 나온 주소로 들어가세요.
화면이 이상하거나 예전 모습입니다브라우저에서 Ctrl + F5(강력 새로 고침)를 눌러 보세요.
다른 컴퓨터·휴대폰에서 입력한 내용이 안 보입니다브라우저마다 따로 저장되기 때문입니다. 시험판의 정상 동작입니다.
입력한 내용이 사라졌습니다브라우저 사이트 데이터를 지우면 사라집니다. 중요한 설정은 프로그램 설정 › 백업에서 내려받아 두세요.
우리 교인 명단을 넣어서 써도 되나요?안 됩니다. 위의 "먼저 알아 두세요"를 보세요.
